## 📋 系统简介

本系统是一款基于 **Streamlit** 构建的隧道工程施工质量验收辅助工具，深度融合《TB 10417-2018 铁路隧道工程施工质量验收标准》和《JTG F80/1-2017 公路工程质量检验评定标准》，彻底解放手工编制内业资料的繁琐工作，实现工程台账的"一键生成、智能推算、大屏可视化"。

---

## ✨ 核心特性

### 🎯 双规范无缝切换

- **铁路隧道**：TB 10417-2018
- **公路隧道**：JTG F80/1-2017

**公路模式下极致对齐规范分项**：
- 洞口工程严格输出 **7 个分项**
- 洞身衬砌精准输出 **11 个分项**
- 剔除一切冗余，直出迎检台账！

### 🏗️ 多级工程管理

- 支持"工程 ➔ 隧道 ➔ 施工段落"三级架构
- 多隧道/通道独立管理
- 支持 `.json` 格式一键导入/导出

### 🧠 智能链式推算

只需要输入各段落工法和长度，系统自动推算所有里程桩号、循环数、进尺数。

### 🎨 企业级数据看板

- **双引擎渲染**：Plotly 交互图表 + Matplotlib 静态图
- 4 大核心统计图表矩阵
- 带有质感的进度条 UI，极大提升汇报演示效果

### 📚 内置规范查阅

- 内置两套标准全文本
- 支持全局智能检索、关键词高亮
- 支持原版 PDF 报告在线缩放阅览

## 📊 检验批划分依据

### 分部工程划分（铁路 TB 10417）

| 序号 | 分部工程 | 说明 |
|------|----------|------|
| 01 | 加固处理 | 危岩处治等 |
| 02 | 洞口工程 | 边坡、导向墙、回填等 |
| 03 | 超前支护 | 锚杆、小导管、注浆等 |
| 04 | 洞身开挖 | CD法、台阶法等 |
| 05 | 初期支护 | 锚杆、钢架、钢筋网、喷射混凝土 |
| 06 | 衬砌工程 | 仰拱、拱墙 |
| 07 | 防水排水 | 防水板、排水管、止水带 |
| 08 | 附属工程 | 排水沟、电缆沟、检修道等 |

### 计算规则

- **CD法**：循环数 × 4步 × 1批 = 洞身开挖批数
- **台阶法**：循环数 × 2步 × 2步 × 1批 = 洞身开挖批数
- **初期支护**：开挖批数 × 4项（锚杆、钢架、钢筋网、喷射混凝土）
- **衬砌工程**：环数 × 3项（模板、钢筋、混凝土）

## 💡 使用指南

### 1. 选择规范
在左侧边栏底部的"应用规范标准"中选择适用的公路或铁路标准。

### 2. 编辑台账
进入「📋 参数配置」页面：
- 点击"新增隧道"添加新隧道
- 在表格中修改【工法】和【长度(m)】
- 点击"保存段落 & 触发智能连缀推算"
- 系统自动算好起止桩号和步数

### 3. 计算检验批
切换到「📊 检验批计算」页面，系统秒级输出：
- 分部汇总表
- 段落明细表
- 分项汇总表
- 支持一键导出 CSV

### 4. 数据洞察
在「📉 统计看板」查看隧道开挖、衬砌比例，掌握项目全局质检负荷。

### 5. 项目保存
在侧边栏使用「📂 数据导入/导出」功能，将配置好的工程导出为 JSON 备份。

## 🔧 常见问题

### Q1: 如何添加新隧道？
在「参数配置」页面，点击「➕ 新增隧道」按钮即可添加。

### Q2: PDF 无法显示？
确保 PDF 文件放置在项目根目录下，命名为 `TB10417-2018.pdf` 或 `JTG_F80_1-2017.pdf`。

### Q3: 图表中文显示乱码？
系统已配置自动检测中文字体（SimHei、SimSun、Microsoft YaHei 等）。

### Q4: 检验批数量不对？
检查施工段落的「工法」「长度」「进尺」「榀距」等参数是否正确。
