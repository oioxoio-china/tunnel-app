# 🚇 隧道工程检验批划分系统 Pro v15.0

> 铁路隧道工程施工质量验收检验批智能划分工具

## 📋 系统简介

本系统是一款基于 Web 的隧道工程检验批划分管理工具，依据《TB 10417-2018 铁路隧道工程施工质量验收标准》设计开发。系统支持隧道工程施工段落的参数配置、智能检验批计算、交互式数据看板以及标准条文查阅等功能。

## 🚀 功能特性

### 1. 📋 参数配置
- **隧道管理**：支持多条隧道（主线、匝道）的添加、编辑、删除
- **工法设置**：支持明挖、CD法、台阶法等多种施工工法的配置
- **纵断面图**：可视化展示隧道施工工法分布（Matplotlib / Plotly 双版本）
- **智能连缀**：输入起始桩号和段长自动计算各段起止里程

### 2. 📊 检验批计算
- **智能计算**：自动提取全线开挖循环数与二衬浇筑环数
- **分部分项**：生成带计算式溯源的检验批汇总表
- **数据导出**：支持 CSV 格式导出（分部汇总、分部分项汇总、详细明细）

### 3. 📉 统计看板
- **Plotly 交互图表**：支持悬停查看、点击筛选、缩放浏览
- **多维度分析**：隧道对比、分部占比、分项频次等
- **数据透视**：支持交叉分析的多维度数据透视表

### 4. 📖 标准查阅
- **全文在线阅读**：内置 TB10417-2018 完整标准条文（15章+附录+条文说明）
- **智能检索**：全局关键字检索，支持高亮显示
- **PDF 原版**：支持 PDF 文件在线预览（需放置 TB10417-2018.pdf）

## 📊 检验批划分依据

### 分部工程划分
| 序号 | 分部工程 | 说明 |
|------|----------|------|
| 01 | 加固处理 | 危岩处治等 |
| 02 | 洞口工程 | 边坡、导向墙、回填等 |
| 03 | 超前支护 | 锚杆、小导管、注浆等 |
| 04 | 洞身开挖 | CD法、台阶法等 |
| 05 | 初期支护 | 锚杆、钢架、钢筋网、喷射混凝土 |
| 06 | 衬砌工程 | 仰拱、拱墙 |
| 07 | 防水排水 | 防水板、排水管、止水带 |
| 08 | 附属工程 | 排水沟、电缆沟、检修道等 |

### 计算规则
- **CD法**：循环数 × 4步 × 1批 = 洞身开挖批数
- **台阶法**：循环数 × 2步 × 1批 = 洞身开挖批数
- **初期支护**：开挖批数 × 4项（锚杆、钢架、钢筋网、喷射混凝土）
- **衬砌工程**：环数 × 3项（模板、钢筋、混凝土）

## 🔧 常见问题

### Q1: 如何添加新隧道？
在「参数配置」页面，点击「➕ 新增隧道」按钮即可添加。

### Q2: PDF 无法显示怎么办？
确保 `TB10417-2018.pdf` 文件放置在与 `streamlit_app_v15_optimized.py` 同一目录下。

### Q3: 图表中文显示乱码？
系统已配置自动检测中文字体（SimHei、SimSun、Microsoft YaHei 等）。如仍有问题，请检查系统是否安装中文字体。

### Q4: 检验批数量不对？
检查施工段落的「工法」「长度」「进尺」「榀距」等参数是否正确。
