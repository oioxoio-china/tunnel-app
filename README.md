# 隧道工程检验批批量生成工具 v18.2

基于 Web 的隧道工程检验批划分与统计工具，支持铁路、公路、高铁隧道检验批的批量生成。

---

## 功能特性

- 支持多隧道同时录入与管理
- 自动化检验批数量计算
- 批量导出检验批表格
- 标准化的分部工程划分
- 支持铁路(TB 10417)、高铁(TB 10753)、公路(JTG F80/1)三种标准

---

## 📊 检验批划分依据

本系统隧道工程质量检验评定支持以下标准：

### 铁路隧道 (TB 10417-2018)

| 序号 | 分部工程 | 分项工程 |
|------|----------|----------|
| 01 | 加固处理 | 地表注浆加固、隧底加固桩 |
| 02 | 洞口及明洞工程 | 洞口开挖、明洞(棚洞)结构、洞门及端翼墙及挡土墙、回填、洞口及明洞边仰坡防护、洞门检查设施 |
| 03 | 洞身开挖 | 开挖 |
| 04 | 支护 | 管棚、超前小导管、水平旋喷桩、超前预注浆、喷射混凝土、钢筋网、系统锚杆、钢架 |
| 05 | 衬砌 | 仰拱(底板)和填充、拱墙衬砌、拱墙回填注浆 |
| 06 | 防水和排水 | 洞口防排水、防(排)水板、涂料防水层、施工缝、变形缝、排水盲管、洞内排水沟(管)、检查井、泄水洞、隧底深埋排水沟、注浆防水 |
| 07 | 辅助坑道 | 开挖、超前支护、初期支护、二次衬砌、坑道口及其封闭 |
| 08 | 附属设施 | 通风土建工程、疏散救援设施、电缆槽 |

### 高铁隧道 (TB 10753-2018)

| 序号 | 分部工程 | 分项工程 |
|------|----------|----------|
| 01 | 加固处理 | 地表注浆加固、洞内预注浆、隧底加固 |
| 02 | 洞口、明洞及缓冲结构 | 洞口开挖、结构工程、回填、防护工程、检查设施 |
| 03 | 洞身开挖 | 开挖 |
| 04 | 支护 | 管棚、超前小导管、水平旋喷桩、喷射混凝土、锚杆、钢筋网、钢架 |
| 05 | 衬砌 | 仰拱(底板)和填充、拱墙衬砌、回填注浆 |
| 06 | 防水和排水 | 洞口防排水、洞内排水沟(管)、检查井、盲管、隧底深埋排水沟、泄水洞、施工缝防水、变形缝防水、防(排)水层防水、注浆防水 |
| 07 | 辅助坑道及洞室 | 开挖、辅助坑道口 |
| 08 | 附属设施 | 通风土建工程、疏散救援设施、电缆槽、综合接地、附属洞室、弃渣场 |

### 公路隧道 (JTG F80/1-2017)

| 序号 | 分部工程 | 分项工程 |
|------|----------|----------|
| 01 | 总体及装饰装修 | 隧道总体、装饰装修工程 |
| 02 | 洞口工程 | 洞口边仰坡防护、洞门和翼墙的浇（砌）筑、截水沟、洞口排水沟、明洞浇筑、明洞防水层、明洞回填 |
| 03 | 洞身开挖 | 洞身开挖(CD法)、洞身开挖(台阶法) |
| 04 | 洞身衬砌 | 超前锚杆、超前小导管、管棚、喷射混凝土、锚杆、钢筋网、钢架、仰拱、仰拱回填、衬砌钢筋、混凝土衬砌（共11项） |
| 05 | 防排水 | 防水层、止水带、排水 |
| 06 | 路面 | 基层、面层（每座隧道仅计2批） |

---

## 使用说明

1. 选择隧道类型（铁路/高铁/公路）
2. 输入隧道名称和长度
3. 系统自动计算检验批数量
4. 导出检验批表格

---

## 技术栈

- Python 3.x
- Streamlit
- Pandas
- Matplotlib/Plotly

---

## 运行方式

```bash
pip install streamlit pandas matplotlib plotly
streamlit run streamlit_app.py
```
